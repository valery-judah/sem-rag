# Agentic Harness Track

## Purpose
`docs/harness-maintain/` is the execution-history area for maintaining the agentic harness in this repo.

Here, `agentic harness` means the documentation system that guides coding agents: routing docs, taxonomy, templates, playbooks, and related maintenance notes. It does not mean the `doc_forge` runtime, retrieval system, or evaluation/runtime harness work inside the service repository.
